# Lettore multimediale WASM

`media.dmapp` contains a Windows 98 Media Player-inspired interface: File/Play/View menus, a black visualizer display, elapsed/duration seek bar, previous/rewind/play-pause/stop/forward/next transport buttons, a mute and volume slider, and a toggleable playlist. Decoding and audio output run in the native host service, outside the WASM app. The seek bar jumps to the selected time; rewind and forward skip ten seconds. Volume is applied in the native decoder path and does not depend on the desktop WASM code.

The visualizer is drawn by the WASM app using the host's rectangle API, so it is part of the Vita screen render as well as the PC preview. It computes a colored Mandelbrot grid on each draw; it does not need a GPU shader.

On the Linux preview, SDL2_mixer handles WAV, MP3 and MIDI when its corresponding decoder is present. libsndfile streams AIFF/AIFC, AU/SND and Creative VOC files. RMI is unwrapped from its RIFF container and then passed to the MIDI decoder. MIDI playback depends on SDL2_mixer's FluidSynth/Timidity decoder and its soundfont/patch data. MP3, MIDI, FLAC, OGG and Opus decoder availability depends on how SDL2_mixer was built. `Mix_LoadMUS` errors are shown in the player if the file or decoder is unavailable. The player reads MP3 ID3v1/v2 title and artist tags and WAV `LIST/INFO` `INAM`/`IART` tags and displays them above the visualizer.

On Vita, the native path delegates WAV, MP3, M4A and MP4 to Sony's AVPlayer/AudioOut modules. CMake now detects and statically links VitaSDK `libsndfile` when installed; that path decodes AIFF/AIFC, AU/SND and VOC PCM through AudioOut. The project setup helper installs the VitaSDK codec packages, including FFmpeg and FluidLite for the remaining container and MIDI backends. These packages are build-time dependencies and are linked into the VPK, so they are not separate apps on the console. This workspace's current VitaSDK is older and lacks them; its present VPK therefore still has only the Sony decoder path. CDA is a track reference, not an audio file; supporting it requires a USB-host/CDDA driver and a mounted optical drive. MP4 video is not drawn by this audio player.

The desktop preview now links SDL2_mixer and libsndfile (`pkg-config` packages `SDL2_mixer` and `sndfile`). Duration and seeking are available for decoders that report a duration; formats without duration metadata show an unknown/zero total. Physical Vita playback has not been verified in this workspace. RDP drive redirection and file transfer remain separate from the media player.
